## Newly Deployed Workflow

```text
operator arms finite mission authority
-> supervisor checkpoints one epoch before execution
-> existing bounded window owner consumes at most one 1-20 step session
-> Observer shows progress, checkpoint, deadline, circuit, and stop reason
-> mission pauses/cancels at an epoch boundary
-> Core restart requires exact explicit re-arm
-> operator may renew only another finite epoch/deadline grant
```

The mission accepts 1-32 epochs initially, at most 32 more per renewal, and at
most 256 during one mission lifetime. Each authority grant is at most seven
days and cannot extend the live horizon beyond 30 days. It is renewable, not
uninterruptible or unbounded.

```text
-> existing bounded window executes it
-> only terminal completion unlocks the next item
```

## Newly Validated Adaptation

```text
operator arms 8-32 finite assignments for one task type
-> Core privately balances baseline and feedback-weighted recall ordering
-> existing provider/application/execution/outcome receipts bind terminal evidence
-> a predeclared Fisher exact rule produces one hash-bound candidate or no change
-> operator explicitly activates or revokes recall ordering only
```

Core restart pauses an open experiment. Assignment is checkpointed before the
provider call, the caller cannot select an arm, and the provider message does
not receive the arm or experiment id. The profile changes neither execution
policy nor authority. Core `963/963`, Observer `118/118`, the real reusable
Core/Observer gate, body-config, and exact `284/114`-file Nix packages pass.
No physical deployment or live experiment result is claimed.

## Newly Validated Multi-Step Workflow

```text
operator explicitly invokes one reviewed form task
-> provider may select only one semantic textbox and write-only value
-> exact task/scene/surface/post-frame/audit evidence authorizes continuation
-> provider may select only one eligible semantic submit button
-> exact post-action verification closes the workflow after step two
```

The workflow never retries, persists input text, completes the task, creates an
approval, or accepts a third action. Core `972/972`, Observer `119/119`, full
workspace tests/typecheck, real Core/Observer capability gates, body-config,
registry/script/path gates, and exact `287/115`-file Nix closures pass. Physical
deployment and a live provider run are not claimed.

## Newly Implemented Fixed Native Workflow

```text
reviewed exact-type task
-> require fixed native intake stopped
-> start exact non-autostarting user unit
-> bind matching activated surface and inventory
-> run existing objective-bound OCR Type once
-> verify task/frame/surface/receipt/post-OCR/audit
-> stop unit, clear transient state, terminate
```

The fixed shell executes no command, has no network family beyond `AF_UNIX`,
persists no input, and accepts no caller-selected unit, process, text, surface,
or action. All `1427/1427` workspace tests, typecheck, Core `980/980`, Observer
`120/120`, Session Manager `85/85`, the real Core/Observer gates, body-config,
and exact `289/36/116`-file Core/Session Manager/Observer closures pass. Physical
activation and a live provider run remain unclaimed.
